# Qurvey — локальний редизайн v1

Запуск: `python -m http.server 8766 --bind 127.0.0.1 --directory qurvey-redesign-v1` з батьківської папки.
Адреса: http://127.0.0.1:8766/

Прототип головної сторінки. Друга секція: Self-service (subscription) та Expert-assisted (per project). Дані й інтерфейси в ілюстраціях демонстраційні. Кнопки реєстрації, кабінету, тарифів і контактів ведуть на поточний qurvey.io. Ціни та непідтверджені комерційні обіцянки не додані.
